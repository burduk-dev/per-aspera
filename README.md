# Per aspera ad asteroid

Браузерная экономическая игра о добыче ресурсов на астероидах и развитии флота.

## Запуск

Проект не требует сборщика, сторонних библиотек или установки зависимостей.

- Из корня репозитория запустите статический HTTP-сервер: `python -m http.server 8000`.
- Откройте `http://localhost:8000` в современном браузере. Не открывайте `index.html` напрямую через `file://`: браузер может заблокировать ES-модули.

## Проверки

Тесты используют встроенный Node.js test runner:

```sh
npm test
```

Требуется Node.js 18+.

## Структура

- `index.html`, `styles.css` — полноэкранный игровой HUD и визуальный стиль.
- `src/config.js` — централизованные стартовые параметры баланса.
- `src/simulation.js` — независимая от Canvas модель и экономические правила.
- `src/builder.js` — модель слотов модулей, расчёт стоимости, совместимости и энергобаланса.
- `src/main.js` — отрисовка, ввод и связь интерфейса с симуляцией.
- `tests/simulation.test.js`, `tests/builder.test.js` — тесты экономики и конструктора.

## Текущий этап

Реализована процедурная звёздная система 7200×7200: одна звезда, одна станция, пять планет, три астероидных пояса и 128 добываемых астероидов с детерминированной генерацией. Торговля, добыча и цены привязаны к единственной станции. Интерфейс переработан в полноэкранную космическую сцену: кредиты и репутация сверху, игровая статистика снизу, панель корабля слева и инженерный режим с квадратными слотами установки прямо на корпусе.

Камеру можно двигать перетаскиванием, приближать/отдалять колёсиком мыши или клавишами `+`/`-`; `R` возвращает обзор системы. Автоисследование выбирает доступные астероиды и возвращает груз на станцию. Поддерживается флот до 3 кораблей с независимыми задачами. Локальное сохранение остаётся следующим этапом по `PLAN.md`.

## Проектные ограничения

- Web / HTML5, desktop-first.
- В UI нет общей строительной сетки: установка модулей выполняется через фиксированные квадратные слоты на корпусе.
- Без боя, угроз, топлива, повреждений, серверов, рекламы и платёжных систем в MVP.
- Балансные значения хранятся в конфигурации, а экономика не зависит от FPS.
